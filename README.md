# Weather App 🌤️

A simple and intuitive weather application built with **HTML**, **CSS**, and **JavaScript** that uses **Axios** for API calls. The app also features live location tracking to provide real-time weather updates based on your current location.

---

## Features 🚀

- **Real-time Weather Updates**: Get the latest weather information for your location.
- **Live Location Tracking**: Automatically fetches your location using the browser's geolocation API.
- **Search Locations**: Search for weather in other cities or regions.
- **Responsive Design**: Optimized for both desktop and mobile devices.
- **Axios Integration**: Efficient API calls using Axios.

---

## How It Works 🛠️

1. **Fetch Location**: The app uses the browser's Geolocation API to get your current coordinates.
2. **Call Weather API**: Using Axios, the app sends your location data to a weather API (e.g., OpenWeatherMap or WeatherAPI) to fetch the latest weather details.
3. **Display Data**: The app displays temperature, humidity, wind speed, and other relevant weather information.
